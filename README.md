# Portfolio Web

Personal portfolio website for Makbul Ridho — SHE professional with a focus on practical digitalization.

## Live site
https://portfolio.maricode.id

## Concept
**SHE × Digital Systems** — a portfolio focused on combining safety practice, management systems, industrial hygiene, and practical digital tools.

## Stack
- HTML
- CSS
- JavaScript
- Nginx on Ubuntu VPS
- GitHub Actions auto-deployment

## Deployment flow
Push to `main` → GitHub Actions → restricted SSH deploy command → VPS → Nginx → production.

## Project structure
- `index.html` — portfolio content and semantic structure
- `css/style.css` — responsive visual system
- `js/script.js` — navigation and lightweight interactions
- `assets/` — future images and icons
- `projects/` — future project case-study pages
